# OctoAcme Project Management Docs

A central guide to OctoAcme's project management processes and supporting documentation.

## Project management process summary

OctoAcme manages work through a customer-focused, iterative lifecycle: initiate and validate an idea, plan scope and milestones, execute and track delivery, release and verify changes, then capture lessons through retrospectives. Project Managers coordinate delivery, risks, dependencies, and communications; Product Managers define outcomes and priorities; developers and QA collaborate to build and validate changes; and stakeholders provide input and approvals. Teams use project boards, clear acceptance criteria and a Definition of Done, regular status and risk reviews, automated quality checks, and appropriate escalation paths to keep work visible and outcomes measurable.
